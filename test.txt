 # What BlitzOS Does

BlitzOS is a minimal x86_64 operating system kernel that demonstrates core OS functionality. Here's what it does:

## Core Functionality

1. **Boot Process**
   - Initializes through GRUB using Multiboot2 specification
   - Sets up basic CPU state and memory mapping
   - Transitions from bootloader to kernel execution

2. **Memory Management**
   - **Paging**: Uses the bootloader's identity-mapped page tables (first 2MB)
   - **Physical Memory**: Tracks free/used pages with a bitmap
   - **Kernel Heap**: Provides dynamic memory allocation for kernel structures

3. **Process Scheduling**
   - Maintains a ready queue of processes
   - Implements simple round-robin scheduling
   - Performs context switching between processes
   - Key functions: `scheduler_init`, `queue_dequeue`, `do_schedule`

4. **Interrupt Handling**
   - Sets up the Interrupt Descriptor Table (IDT)
   - Handles hardware interrupts (keyboard, timer) and exceptions
   - Saves/restores processor state during interrupts
   - Uses `isr_common_stub` as the assembly entry point for all interrupts

5. **Device Drivers**
   - **Keyboard**: Handles key presses and displays them on screen
   - **PIT (Programmable Interval Timer)**: Provides system timing
   - **VGA**: Text-mode display output

## Data Flow Example (Keyboard Input)

1. User presses a key → generates hardware interrupt
2. CPU jumps to ISR stub (`isr_common_stub`)
3. Assembly code saves processor state
4. C handler (`isr_handler`) processes the interrupt
5. Keyboard driver reads scan code and converts to character
6. Character is displayed via VGA driver
7. Processor state is restored and execution continues

## Key Modules

- **Interrupt Handling** (`kernel/arch/x86_64/`): Processes hardware events
- **Device Drivers** (`drivers/`): Provides hardware abstraction

BlitzOS is primarily educational - it demonstrates fundamental OS concepts in a simple, understandable implementation while being functional enough to run in an emulator.
